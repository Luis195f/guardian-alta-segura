# DEC-017 — Formulario institucional de decisión

## Instrucciones

Completar con información institucional aprobable y referencias versionadas. No
incluir nombres de pacientes, approvers, datos clínicos, teléfonos ni otra
PHI/PII. La identidad nominal del approver, firma o acta permanece en el sistema
institucional correspondiente. Este repositorio conserva únicamente el rol y una
referencia minimizada a esa evidencia.

`DEC-017-A` a `DEC-017-I` son identificadores de trabajo para descomponer la
decisión canónica `DEC-017`. No son registros canónicos independientes salvo que
el proceso de gobernanza aplicable los promueva formalmente a
`docs/decision-register.md`.

Solo `Pendiente`, `Propuesta`, `Aprobada`, `Retirada` y `Sustituida` son estados
canónicos de DEC-017. `DRAFT`, `UNDER_REVIEW` y `FINAL` describen exclusivamente
el estado de trabajo de este documento y no cambian el estado de la decisión.

Clasificación vigente: DEC-017-C, D, E y F son `BLOCKING_FOR_SLA`.
DEC-017-H es `BLOCKING_FOR_ESCALATION` y
`BLOCKING_FOR_PROCESS_SAFETY` cuando Process Safety depende de escalation.
DEC-017-C, D, E, F, G e I son
`CONDITIONAL_BLOCKER_FOR_ESCALATION` cuando la condición aprobada depende de
esa dimensión. DEC-017-A, B, G e I son `CONDITIONAL_BLOCKER` para el alcance
combinado y solo pasan a `CAN_DEFER` cuando el alcance aprobado declara que no
usa esa dimensión.

## Resultado del gate institucional

| Campo | Valor |
|---|---|
| Canonical DEC-017 status after review | `Pendiente / Propuesta / Aprobada / Retirada / Sustituida` |
| Working decomposition items resolved for scope | |
| Working decomposition items deferred | |
| Blocking evidence still missing | |
| Approved scope | |
| Policy version | |
| Approval evidence reference | |
| Effective date | |
| Required consultative evidence | |
| Contradictions between selected options | |
| Explicitly excluded scope | |
| Next gate | `READY_FOR_INSTITUTIONAL_DECISION / READY_FOR_TECHNICAL_SPECIFICATION / READY_FOR_IMPLEMENTATION` |

Crear este formulario o marcarlo `FINAL` no autoriza implementación. El gate
`READY_FOR_TECHNICAL_SPECIFICATION` requiere
`Canonical DEC-017 status = Aprobada` para la policy version y el approved scope
que se pretende especificar, además de referencia de evidencia, versión de
política, alcance aprobado, fecha efectiva, todos los blockers del alcance
resueltos, evidencia consultiva aplicable y ausencia de contradicciones entre
opciones. `Pendiente`, `Propuesta` y `Retirada` no permiten avanzar; `Sustituida`
tampoco lo permite para la versión sustituida. La historia se conserva.

```text
READY_FOR_INSTITUTIONAL_DECISION
→ institutional evidence/approval
→ READY_FOR_TECHNICAL_SPECIFICATION
→ technical design review
→ READY_FOR_IMPLEMENTATION
```
